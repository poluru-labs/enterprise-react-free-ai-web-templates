# KnowPulse · AI Knowledge Base

Light enterprise dashboard to manage articles, sources, citations, freshness, and knowledge gaps. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5202  
Preview server: http://127.0.0.1:4202

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/kb/overview`, `/kb/articles`, `/kb/sources`, `/kb/citations`, `/kb/freshness`, `/kb/gaps`, `/kb/settings`.
