# Algorithmic Fairness Auditor (ParityDesk)

Bias metrics, cohort reviews, policy checks, and remediation workflows — light theme **`#04536C`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5208 → `/fairness/overview`

## Routes

- `/fairness/overview` — Program snapshot and activity
- `/fairness/metrics` — Disparity metrics and floors
- `/fairness/cohorts` — Segment reviews
- `/fairness/policies` — Thresholds and exceptions
- `/fairness/reviews` — Certification queue
- `/fairness/settings` — Floors and alert windows
