# Knowledge Base (KbDesk)

Modern **TypeScript + Vite + SCSS modules** workspace for articles, categories, maintenance, assistant chat, and authoring playbooks. Brand **`#E00000`**, Roboto and Lato.

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

## Routes

| Path | Feature |
| --- | --- |
| `/` | Overview KPIs |
| `/articles` | Article library |
| `/categories` | Category taxonomy |
| `/maintenance` | Refresh queue |
| `/chat` | Knowledge assistant |
| `/agents` | Playbooks |
| `/settings` | Workspace settings |

See **`AGENTS.md`** for the five-commit implementation checklist.
