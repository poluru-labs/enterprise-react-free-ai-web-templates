# Research Reproducibility Workbench (ReproDesk)

Experiment runs, artifacts, environment pins, and reproduction status — light theme **`#4E1F6E`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5218 → `/repro/overview`

## Routes

- `/repro/overview` — Program snapshot and activity
- `/repro/runs` — Experiment run log
- `/repro/artifacts` — Sealed outputs vault
- `/repro/environments` — Pinned dependency stacks
- `/repro/reproductions` — Verification tracker
- `/repro/settings` — Thresholds and notifications
