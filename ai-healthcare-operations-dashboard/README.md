# ClinicPulse · AI Healthcare Operations

Light enterprise dashboard to monitor clinical queues, summaries, coding, and privacy events. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5200  
Preview server: http://127.0.0.1:4200

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/clinical/overview`, `/clinical/queues`, `/clinical/summaries`, `/clinical/coding`, `/clinical/privacy`, `/clinical/settings`.
