# ContractPulse · AI Legal Contract Intelligence

Light enterprise dashboard to extract clauses, track obligations, and manage contract reviews. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5203  
Preview server: http://127.0.0.1:4203

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/legal/overview`, `/legal/clauses`, `/legal/obligations`, `/legal/reviews`, `/legal/settings`.
