# Open Source Maintainer Workspace (MaintDesk)

Issues, releases, contributors, and package health — light theme **`#F5824A`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5215 → `/maint/overview`

## Routes

- `/maint/overview` — Maintainer snapshot and activity
- `/maint/issues` — Issue triage
- `/maint/releases` — Tags and downloads
- `/maint/contributors` — Community roster
- `/maint/packages` — Health and advisories
- `/maint/settings` — SLAs and notifications
