# Disaster Resource Coordinator (ReliefDesk)

Inventory, deployments, requests, and regional status — light theme **`#8C56D4`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5213 → `/relief/overview`

## Routes

- `/relief/overview` — Ops snapshot and activity
- `/relief/inventory` — Warehouse stock
- `/relief/deployments` — Convoys and ETAs
- `/relief/requests` — Site request queue
- `/relief/regions` — Regional status
- `/relief/settings` — Floors and notifications
