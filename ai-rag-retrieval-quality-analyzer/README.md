# Retrieval Quality Analyzer (RqDesk)

Query logs, precision/recall style KPIs, corpus coverage, and review queues — light theme **`#6B3F69`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5217 → `/rq/overview`

## Routes

- `/rq/overview` — Quality snapshot and activity
- `/rq/queries` — Query session log
- `/rq/kpis` — KPI board by cohort
- `/rq/corpus` — Source coverage inventory
- `/rq/reviews` — Human spot-check queue
- `/rq/settings` — Targets and notifications
