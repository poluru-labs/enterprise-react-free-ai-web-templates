# Semantic Search (SearchDesk)

Modern **TypeScript + Vite + SCSS** workspace for query logs, indexes, rankings, evaluations, assistant chat, and tuning playbooks. Brand **`#FF5A22`**, Roboto and Lato.

```bash
npm install
cp .env.example .env
npm run dev
```

| Path | Feature |
| --- | --- |
| `/` | Overview |
| `/queries` | Query log |
| `/indexes` | Index inventory |
| `/rankings` | Ranking metrics |
| `/evaluations` | Eval queue |
| `/chat` | Search assistant |
| `/agents` | Playbooks |
| `/settings` | Settings |

See **`AGENTS.md`** for the five-commit checklist.
