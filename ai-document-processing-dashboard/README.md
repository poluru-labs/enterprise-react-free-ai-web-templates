# Pagewise · Document Ops

Light enterprise dashboard for OCR, classification, extraction, validation, and exceptions. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5194
Preview server: http://127.0.0.1:4194

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/documents/overview`, `/inbox`, `/classify`, `/extract`, `/validate`, `/exceptions`, `/settings`.
