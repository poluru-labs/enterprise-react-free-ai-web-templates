# PlanPulse · AI Forecasting & Planning

Light enterprise dashboard to manage predictions, scenarios, confidence levels, and accuracy. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5199  
Preview server: http://127.0.0.1:4199

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/forecast/overview`, `/forecast/predictions`, `/forecast/scenarios`, `/forecast/confidence`, `/forecast/accuracy`, `/forecast/settings`.
