# Scientific Literature Mapper (LitDesk)

Corpus mapping, topic clusters, citation links, and curation tasks — light theme **`#118AB2`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5219 → `/lit/overview`

## Routes

- `/lit/overview` — Library snapshot and activity
- `/lit/corpus` — Paper mapping
- `/lit/clusters` — Topic clusters
- `/lit/citations` — Citation link registry
- `/lit/curation` — Curation task queue
- `/lit/settings` — Policy and notifications
