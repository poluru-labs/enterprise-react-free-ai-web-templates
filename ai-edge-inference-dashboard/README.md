# CareLine · Healthcare Ops

Light enterprise dashboard for clinical queues, summaries, coding, and privacy events. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5195
Preview server: http://127.0.0.1:4195

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/healthcare/overview`, `/queues`, `/summaries`, `/coding`, `/privacy`, `/settings`.
