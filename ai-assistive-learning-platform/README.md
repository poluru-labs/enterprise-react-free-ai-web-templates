# Assistive Learning Platform (LearnDesk)

Learner progress, accommodations, content modules, and support tickets — light theme **`#F45905`**, Roboto and Lato, powered by `@poluru-labs/enterprise-design-system-react`.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:5209 → `/learn/overview`

## Routes

- `/learn/overview` — Term snapshot and activity
- `/learn/learners` — Roster and progress
- `/learn/modules` — Content paths
- `/learn/accommodations` — Requests and approvals
- `/learn/support` — Ticket desk
- `/learn/settings` — Floors and notifications
