# Agent Builder Studio

Vite + React studio for building agent **tools, workflows, memory, tests, and deployments**. Uses `@poluru-labs/enterprise-design-system-react` with theme color `#17433F`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Dev server: http://127.0.0.1:5189  
Preview: http://127.0.0.1:4189

Open `/studio/overview`.
