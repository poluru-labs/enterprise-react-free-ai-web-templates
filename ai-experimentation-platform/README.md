# VariantLab · Experiment Ops

Light enterprise dashboard for model variants, experiments, metrics, and rollout gates. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5197
Preview server: http://127.0.0.1:4197

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/lab/overview`, `/variants`, `/experiments`, `/metrics`, `/rollouts`, `/settings`.
