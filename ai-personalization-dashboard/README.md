# AI Personalization Dashboard

PersonaDesk — manage user segments, journeys, recommendations, and retention on a light desk powered by `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5200

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

- `/personalize/overview` — Home snapshot
- `/personalize/segments` — User segments
- `/personalize/journeys` — Journey orchestration
- `/personalize/recommendations` — Recommendation slots
- `/personalize/retention` — Cohorts and save plays
- `/personalize/settings` — Desk settings
