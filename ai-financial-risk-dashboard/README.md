# RiskPulse · Financial Risk

Light enterprise dashboard for fraud, credit models, portfolio risk, and explainability. Built with Vite, React, and `@poluru-labs/enterprise-design-system-react`.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Default dev server: http://127.0.0.1:5198
Preview server: http://127.0.0.1:4198

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |

## Routes

`/risk/overview`, `/fraud`, `/credit`, `/portfolio`, `/explain`, `/settings`.
